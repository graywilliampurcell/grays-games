# Mazle Development Plan

## Functional Specification

### Overview
Mazle is a cooperative multiplayer mobile game that allows up to **10 players** to navigate a maze together. The goal is to reach the exit by solving puzzles and utilizing teamwork.

### Gameplay Features
1. **Starting Setup**:
   - Players begin **at a starting line** within the maze.
   - Players can select their **character and skin** (similar to Minecraft) before the game starts.

2. **Maze Layout**:
   - The layout of the maze is **fixed** before the game starts to ensure fairness.
   - Players can find and collect a **map of the maze**, which displays the entire layout.

3. **Interactive Elements**:
   - Levers, switches, and other interactive objects are scattered throughout the maze.
   - Activating these will **open doors** or reveal new paths for the team.

4. **Progression**:
   - Players start the game in a **main menu** with a green background and buttons for levels from **1 to 300**.
   - Players can only start at **Level 1** and must complete levels sequentially to unlock harder challenges.
