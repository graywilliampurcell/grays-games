# Mazle Map Playtest

A bare-bones map exploration experience for testing movement and navigation.

## Setup

```bash
cd src/playtest
npm install
npm run dev
```

Then open your browser to `http://localhost:5173`

## Controls

- **W/↑** - Move forward
- **S/↓** - Move backward
- **A/←** - Strafe left
- **D/→** - Strafe right
- **Mouse** - Look around (click to enable pointer lock)

## Features

- First-person movement
- Collision detection with maze walls
- Simple maze layout
- FPS counter and position display
- Smooth acceleration and friction
