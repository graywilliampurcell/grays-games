# Comparable games

Reference ideas from the plan's Part 1. A game's own Tester profile decides which of these (or others) it is compared against; with no profile, Claude picks a few and names them in the report.

**Every profile below is from general knowledge, not played.** Replace with a human-speed session profile (never crawling, no downloaded videos, keep only our notes) when one is made. Ads and purchases are flagged only.

---

## Mazes

### A Maze Race
```yaml
source: general-knowledge-not-played
genre: top-down maze, racing a timer/opponent
web_playable: yes (classic Flash-era web game; HTML5 ports on kids' game sites)
onboarding: drop straight into a small maze; arrow keys shown in a short note
controls: arrow keys (held); some versions mouse
core_loop: find the path from start to finish before the opponent/timer
goals_and_rewards: reach the exit; next, bigger maze; little celebration
difficulty_curve: mazes grow steadily; time pressure is the main difficulty
game_feel: simple, crisp grid movement
art_and_audio: bright cartoon, basic sound
session_length: 1–3 min per maze
usability: very clear goal; text instructions
accessibility: colour-coded paths; needs reading and held keys
ads_and_purchases: host sites typically show ads around the game
compare_for: pacing of maze size ramp; time pressure (not OK for 2–4)
```

### Maze Control
```yaml
source: general-knowledge-not-played
genre: tilt/rotate-the-maze puzzle
web_playable: yes (browser game on kids' portals)
onboarding: first levels are trivially short
controls: arrow keys or mouse to rotate/tilt the maze, gravity moves the ball
core_loop: rotate the world so the ball reaches the goal
goals_and_rewards: reach goal; level count progress
difficulty_curve: gradual; later levels add hazards
game_feel: physics-driven, satisfying roll
art_and_audio: simple, clean
session_length: under a minute per level
usability: indirect control can confuse young kids
accessibility: low text; indirect control
ads_and_purchases: portal ads
compare_for: indirect vs direct control; short level length
```

### PBS KIDS mazes (e.g. character maze games on pbskids.org)
```yaml
source: general-knowledge-not-played

web_playable: yes (pbskids.org, PBS KIDS Games app)
onboarding: a known character speaks the goal; replay-voice button
controls: tap/click or drag along the path; arrows on desktop
core_loop: guide the character to a friend/item
goals_and_rewards: character celebrates; stickers/collectibles in some games
difficulty_curve: very gentle; almost no failing
game_feel: soft, friendly feedback on every tap
art_and_audio: show characters, full voice-over, music
session_length: 3–10 min
usability: built for pre-readers; hints if idle
accessibility: large targets, audio-first, no reading needed
ads_and_purchases: none (non-commercial)
compare_for: onboarding and voice-over; idle hints; kind failure
```

### Pac-Man
```yaml
source: general-knowledge-not-played
genre: arcade maze chase
web_playable: yes (Google Doodle Pac-Man; official web versions)
onboarding: none; learn by playing
controls: arrow keys / swipe, single direction at a time
core_loop: eat dots, avoid ghosts, eat power pellet to turn the tables
goals_and_rewards: clear the maze; score, fruit bonuses
difficulty_curve: speeds up each level; lives system
game_feel: tight, instant response; iconic sound on every dot
art_and_audio: high-contrast, readable; constant audio feedback
session_length: 2–10 min per game
usability: instantly clear goal
accessibility: fast reactions needed; ghost chase is threatening for 2–4
ads_and_purchases: none in classic/Doodle
compare_for: feedback and pacing; sound on every pickup (chase itself is not a model for young brackets)
```

### Monument Valley
```yaml
source: general-knowledge-not-played

web_playable: no (iOS/Android/PC apps)
```

## Ball and racing

### Super Monkey Ball
```yaml
source: general-knowledge-not-played
genre: tilt-the-stage ball rolling
web_playable: no (console/PC/mobile)
onboarding: first stages are wide and flat
controls: one stick tilts the world; no buttons in core play
core_loop: roll the ball to the goal gate within the time limit
goals_and_rewards: goal gate celebration, bananas as collectibles
difficulty_curve: worlds ramp; later stages are very hard
game_feel: excellent physics and camera; strong juice
art_and_audio: bright, cheerful, announcer voice
session_length: 30–60 s per stage
usability: instant retry after falling out
accessibility: timer on every stage; fine control needed later
ads_and_purchases: none in main releases (some mobile versions differ)
compare_for: camera, fall-out-and-retry loop, collectibles along the line
```

### Marble It Up
```yaml
source: general-knowledge-not-played
genre: 3D marble platformer / time trial
web_playable: no (PC/console)
onboarding: tutorial levels introduce jump and power-ups
controls: move + jump, camera stick
core_loop: roll through a course to the finish; chase medal times
goals_and_rewards: finish, gems, medal times, marble skins
difficulty_curve: moderate; optional speed-run depth
game_feel: responsive, satisfying momentum
art_and_audio: clean, bright
session_length: 1–3 min per level
usability: instant restart
accessibility: two-input + camera; timer-focused
ads_and_purchases: paid up-front; cosmetic DLC
compare_for: skins as rewards, checkpoint/restart speed, medal tiers
```

### Slope

```yaml
source: general-knowledge-not-played
```

### Mario Kart (Mario Kart 8 Deluxe / Tour)
```yaml
source: general-knowledge-not-played
genre: kart racing
web_playable: no (Nintendo Switch; Tour on mobile)
onboarding: menus with icons; smart steering and auto-accelerate assists
controls: steer + accelerate + item; assists make it one-stick
core_loop: race 3 laps, use items, place well
goals_and_rewards: placements, trophies, unlocks
difficulty_curve: CC classes; AI rubber-banding keeps races close
game_feel: best-in-class; drift and boost feedback
art_and_audio: bright, iconic characters, lively music
session_length: ~2–3 min per race; cups ~10 min
usability: assists let 4–6-year-olds finish races
accessibility: smart steering, auto-accelerate
ads_and_purchases: none on Switch; Tour had gacha "pipes" (avoid pattern, rule R12)
compare_for: assist modes for young kids; AI racers that keep it close; celebrations
```
